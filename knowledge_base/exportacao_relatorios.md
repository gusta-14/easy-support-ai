## Procedimento para exportar dados
Para exportar ou baixar uma cópia de um relatório, navegue até ao módulo "Relatórios" no menu esquerdo, selecione os filtros de data desejados e clique no botão verde "Exportar para CSV".

## Exceções
A exportação de dados com mais de 5 anos deve ser solicitada diretamente à equipa de dados através de um chamado de suporte.
